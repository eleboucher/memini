memini is deployed.

Service: {{ .Release.Name }}.{{ .Release.Namespace }}.svc:8080

Port-forward and check health:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }} 8080:8080
  curl localhost:8080/healthz

Endpoints:
  REST    : /v1   (e.g. /v1/memories, /v1/search, /v1/fsck)
  MCP     : /mcp  (Streamable HTTP)
  Admin UI: /     (embedded SPA, when MEMINI_UI_ENABLED=true)

Exposing /v1 or /mcp off-cluster (via the `route` values) REQUIRES bearer auth:
set MEMINI_API_KEY on controllers.main.containers.main.env from a Secret. Clients
must then send: Authorization: Bearer <api-key>
