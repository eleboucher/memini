# memini for OpenCode V2

The V2 entrypoint for memini's automatic OpenCode memory plugin.

```jsonc
{
  "plugins": ["@eleboucher/opencode-memini-v2"],
}
```

Configure options with OpenCode's object form:

```jsonc
{
  "plugins": [
    {
      "package": "@eleboucher/opencode-memini-v2",
      "options": { "namespace": "my-project" },
    },
  ],
}
```
